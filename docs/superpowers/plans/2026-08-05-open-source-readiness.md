# 开源就绪实施计划

> **供智能体执行：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，严格按任务顺序执行。所有步骤使用复选框跟踪。

**目标：** 以 Apache-2.0 协议完成 Starpay 支付网关开源准备，清零已知可达后端漏洞和全部前端依赖漏洞，建立 GitHub Actions CI/安全门禁，并补齐公开协作与安全文档。

**架构：** 先删除不属于产品源码的第三方开发环境材料并建立许可证边界；随后通过测试驱动强化生产配置、升级后端和前端依赖；最后以快速 CI、周期安全扫描和公开文档形成持续门禁。支付网关使用独立的 `zmoyi/starpay` 仓库，现有 `zmoyi/starpay-go` SDK 仓库继续独立发布。

**技术栈：** Go 1.26.5、Gin、Ent、Bun 1.3.13、React、Rsbuild、Docker、GitHub Actions、CodeQL、gitleaks 8.30.1、Trivy 0.73.0、Syft SBOM。

## 全局约束

- 根仓库许可证固定为 Apache License 2.0；`sdk/go` 继续使用 MIT。
- 根模块和 SDK 模块统一声明 `toolchain go1.26.5`。
- 后端发布门禁是 `govulncheck ./...` 报告 0 个可达漏洞。
- 前端发布门禁是包含开发依赖的 `bun audit` 报告 0 个漏洞。
- `golang.org/x/text` 不低于 v0.39.0；`github.com/quic-go/quic-go` 不低于 v0.59.1。
- `@tailwindcss/postcss` 和 `tailwindcss` 固定到兼容范围 `^4.3.3`，`postcss` 精确固定为 `8.5.25`，删除仓库依赖中的 `shadcn` CLI。
- Docker 构建镜像使用 `oven/bun:1.3.13`、`golang:1.26.5` 和 `alpine:3.23`；Compose 中 PostgreSQL、Redis 继续使用 `latest`。
- GitHub Action 必须固定到不可变提交 SHA，并在同行注释对应版本。
- 不允许通过宽泛路径、宽泛正则或忽略真实漏洞来获得绿色扫描结果。
- 所有 API 行为继续使用 `{ code, message, data, error }`；本计划不新增业务 API。
- 后端改动完成后必须构建最新 `bin/payment-gateway`，确认并替换本仓库正在运行的旧后端进程，再交付测试。
- 不在本计划中创建公开仓库、推送 GitHub、发布镜像或创建 Release；这些是所有门禁通过后的仓库所有者操作。

```go
func validateProductionSecrets(cfg Config) error {
	if !strings.EqualFold(cfg.App.Env, "production") {
		return nil
	}
	if cfg.Auth.JWTSecret == defaultJWTSecret {
		return fmt.Errorf("JWT_SECRET must not use the development default in production")
	}
	if cfg.Auth.AppSecretEncryptionKey == defaultAppSecretEncryptionKey {
		return fmt.Errorf("APP_SECRET_ENCRYPTION_KEY must not use the development default in production")
	}
	values := []struct {
		name  string
		value string
	}{
		{name: "JWT_SECRET", value: cfg.Auth.JWTSecret},
		{name: "APP_SECRET_ENCRYPTION_KEY", value: cfg.Auth.AppSecretEncryptionKey},
		{name: "DATABASE_URL", value: cfg.Database.DSN},
		{name: "REDIS_PASSWORD", value: cfg.Redis.Password},
	}
	for _, item := range values {
		if strings.Contains(strings.ToUpper(item.value), "CHANGE_ME") {
			return fmt.Errorf("%s contains an unreplaced CHANGE_ME value", item.name)
		}
	}
	return nil
}
```
